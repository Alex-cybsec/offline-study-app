# Offline Study App

An Android app that saves study content (articles, videos, PDFs) 
while on WiFi and lets students browse it offline.

## Status
🚧 In development — currently learning Android + Kotlin

## Goal
Help students study anywhere, even without internet.

## Tech (planned)
- Kotlin
- Jetpack Compose
- Room (local database)
- WorkManager (WiFi-triggered fetching)

## Roadmap
- [ ] v1: Save a URL → read offline
- [ ] v2: In-app browser
- [ ] v3: Smart content suggestions
- [ ] v4: Video + PDF support
